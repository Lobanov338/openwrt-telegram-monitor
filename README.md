OpenWrt 24.10+
Telegram Bot API
Установка одной командой через curl -fsSL .../install.sh | sh

Красивое меню Telegram с кнопками
Мониторинг CPU, RAM, Flash, uptime
WAN/IP/интернет
Список DHCP-клиентов
Конфигурация через /etc/telegram-monitor/config

uninstall.sh
